# MILLENIUM

Toolkit para Tribal Wars BR.

## Instalação

1. Instale a extensão **[Tampermonkey](https://www.tampermonkey.net/)** no seu navegador
2. Clique no link abaixo para instalar o script:

👉 **[Instalar MILLENIUM](https://raw.githubusercontent.com/MateusObozovski/MogScripts/refs/heads/claude/tribal-wars-bot-XMdg5/dist/Mog.user.js)**

3. Clique em **"Instalar"** na tela do Tampermonkey
4. Abra o Tribal Wars e vá na tela do **Armazém** — o painel do bot aparece automaticamente

## Atualização

O script atualiza automaticamente pelo Tampermonkey. Para forçar uma atualização manual:

1. Abra o Tampermonkey → aba **Utilitários**
2. Clique em **Verificar atualizações**
